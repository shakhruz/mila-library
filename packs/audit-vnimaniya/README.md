# Аудит внимания · Attention audit

**Что даёт.** Зеркало без советов: вы называете главное дело и то, что читали, смотрели и слушали за неделю, — я раскладываю
это на «помогает делу», «рассеивает» и «полезно в своё время», показываю доли, три повторяющихся рисунка и три вопроса себе.
Без «надо» и «следует».

**Где лежит.** Зеркало — в `~/work/library/audit-vnimaniya.md` (у Милы, закрытое место; для другого человека по слову хозяина — `audit-vnimaniya-<ярлык>.md`). Удаление пака его не трогает.
