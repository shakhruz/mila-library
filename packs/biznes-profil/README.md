# Бизнес-профиль · Business profile

**Что даёт.** Мила собирает профиль вашего дела в одном файле `~/work/PROFILE.md`: чем занимаетесь, для кого, продукты и цены,
каналы, команда, цифры, что мешает расти. Профиль — основа для следующих паков: они будут брать факты отсюда,
а не спрашивают заново.

**Где лежит.** `~/work/PROFILE.md` — ваш файл, не пака: удаление пака его не трогает. Телефоны, адреса и данные людей в нём —
метками pd-vault; файл не уходит в экспорт, посты и git.

**What it gives.** Mila gathers your business profile in one file, `~/work/PROFILE.md` — the base the next packs read from.
The file is yours, not the pack's: removing the pack keeps it. Personal data in it goes through pd-vault.
