# Профориентация · Career direction

**Что даёт.** Три вопроса — и короткий разбор: 2–3 направления, каждое с причиной из ваших же слов, и один маленький
эксперимент на неделю, чтобы проверить направление делом. Это взгляд для размышления, не тест и не диагноз.

**Где лежит.** Разбор — в `~/work/library/proforientatsiya.md` (у Милы, закрытое место; для другого человека по слову хозяина — `proforientatsiya-<ярлык>.md`). Удаление пака его не трогает.

**What it gives.** Three questions, then a short look: 2–3 directions, each with a reason in your own words, and one small
experiment for the week. A view to think about, not a test or a diagnosis.
